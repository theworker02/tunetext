# tunetext

Tune structured JSON text payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/tunetext/

## Install / run

```bash
git clone https://github.com/theworker02/tunetext.git
cd tunetext
node src/cli.js
node --test
```
